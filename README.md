# PropScore Redesign

Full-stack property scoring and real estate analytics platform with modern UI, property comparison, and market trend visualization.

## Features

- Property scoring algorithm based on location, amenities, and market data
- Side-by-side property comparison
- Market trend charts and neighborhood analytics
- Saved searches and property watchlists
- Responsive modern UI redesign

## Tech Stack

TypeScript, React, Node.js, PostgreSQL, Chart.js

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/karthik-idikuda/propscore-redesign.git
cd propscore-redesign
npm install
```

### Usage

```bash
npm run dev
```
